# Запуск в фастфуде: пошагово

Цель: за один вечер поднять систему и на следующий день отработать смену параллельно с тем, как кухня работает сейчас.

## Что нужно

| Что | Где взять | Стоимость |
|---|---|---|
| Сервер Ubuntu 24.04, 2 ГБ памяти | Hetzner Cloud, локация Helsinki (ближе всего к Таллину) | около 5 € в месяц |
| Токен API Poster | Админка Poster → «Доступ» → «Интеграция» | бесплатно |
| Планшет на кухню | любой Android или iPad с Chrome или Safari, лучше 10" | есть у клиента |
| Телевизор у стойки выдачи | любой Smart TV с браузером или ТВ-приставка | есть у клиента |
| Wi-Fi на кухне | стабильный сигнал у места планшета | — |

## 1. Сервер (15 минут)

1. Создайте сервер в Hetzner Cloud: Ubuntu 24.04, локация Helsinki, самый маленький тариф. Запишите IP-адрес.
2. Загрузите на него архив `poster-kds-1.0.0-beta.1.zip` и распакуйте его:
   ```
   scp poster-kds-1.0.0-beta.1.zip root@IP:/opt/
   ssh root@IP
   cd /opt && apt-get install -y unzip && unzip poster-kds-1.0.0-beta.1.zip && cd kds
   ```
3. Запустите одной командой (подставьте свой токен и имя аккаунта Poster: то, что стоит перед `.joinposter.com`):
   ```
   sudo POSTER_TOKEN=ваш_токен POSTER_ACCOUNT=имя_аккаунта VENUE_TYPE=fastfood ./install.sh
   ```
4. В конце установщик покажет адрес вида `https://1-2-3-4.sslip.io`, пароль платформы и пароль админки. Сохраните их.

Домен `sslip.io` временный, но с настоящим HTTPS. Свой домен можно подключить позже: `sudo DOMAIN=kds.вашдомен.ee ./install.sh`.

## 2. Настройка в админке (15 минут)

Откройте `https://…/admin/`. Вход: имя аккаунта Poster и пароль из установщика.

1. **Состояние.** «Poster: онлайн», меню загружено.
2. **Станции.** Уже созданы «Кухня» и «Выдача». Если в Poster есть цеха (гриль, фритюр, напитки), привяжите их к станциям. Напитки, которые кассир наливает сам, можно не выводить на кухню.
3. **Сотрудники.** Повара и кассиры подтягиваются из Poster. Каждому, кто будет отмечать заказы, задайте PIN из 4 цифр.
4. **Позиции.** Поставьте ставку за порцию, если платите сдельно, и норму времени для основных блюд (бургер 4–5 минут, фри 3 минуты).
5. **Настройки.** Проверьте, что «Формат заведения» — «Фастфуд», валюта EUR, часовой пояс Europe/Tallinn.
6. **Агрегаторы доставки** (в «Настройках»). Пробейте или примите один заказ Wolt или Bolt Food и посмотрите, что пишется в его комментарии или от какого сотрудника он пришёл. Если там есть слово «Wolt» / «Bolt», метка поставится сама. Если нет, впишите в правило то слово, которое там есть.

## 3. Экраны (10 минут)

- **Планшет на кухне.** «Экраны и кассы» → «+ Экран», станция «Кухня». На планшете откройте `https://…/kds/` и введите 6-значный код. Добавьте страницу на главный экран, выключите автоблокировку, держите на зарядке.
- **Экран выдачи** (если кассир отдаёт заказы с отдельного планшета): так же, станция «Выдача». Если отдельного планшета нет, ничего страшного: готовый заказ сам уйдёт с экрана для гостей через 10 минут.
- **Телевизор для гостей.** «Экраны и кассы» → «Экран выдачи для гостей» → «Копировать ссылку». Откройте ссылку в браузере телевизора и один раз коснитесь экрана (или нажмите OK на пульте), чтобы включить звук и полный экран.

### Как поставить экран как приложение

Экран ставится как обычное приложение с иконкой, без магазинов. Обновления приходят сами.

| Устройство | Как установить | Чтобы повар не вышел из приложения |
|---|---|---|
| Android-планшет | Chrome → адрес `https://…/kds/` → меню ⋮ → «Установить приложение» | Fully Kiosk Browser (около 7 € за устройство): автозапуск при включении, экран не гаснет, выйти нельзя |
| iPad | Safari → адрес → «Поделиться» → «На экран Домой» | Настройки → Универсальный доступ → «Гид-доступ», потом трижды нажать боковую кнопку в приложении |
| Windows | Edge или Chrome → адрес → значок «Установить» в адресной строке | Режим киоска Windows (Параметры → Учётные записи → Киоск) |
| Телевизор | Браузер телевизора → ссылка экрана выдачи | — |

На планшете: выключите автоблокировку экрана и держите его на зарядке.

## 4. Проверка перед сменой (10 минут)

1. Пробейте на кассе тестовый заказ «с собой» и оплатите его.
2. Через 4–5 секунд он появится на кухне с номером (последние три цифры чека) и пометкой «С собой».
3. На телевизоре номер стоит в колонке «Готовится».
4. Повар нажимает на позицию, выбирает себя (или вводит PIN), потом «Готово».
5. Номер переходит в «Готово — заберите», звучит сигнал.
6. На выдаче нажмите «Отдано»: номер пропадает с телевизора.
7. В админке «Отчёты» видно, кто приготовил и кто отдал.
8. Удалите тестовый чек в Poster: на кухне он покажется как отменённый.

## 5. Первая смена

- **Первые 2–3 дня работайте параллельно:** принтер на кухне не выключайте, KDS работает рядом. Так ничего не потеряется, если что-то пойдёт не так.
- **Каждый вечер сверяйте** в админке «Контроль» и «Отчёты» с чеками Poster за день: каждая позиция должна быть на экране и отмечена.
- **Что записывать:** заказы, которые пришли на экран с опозданием больше 10 секунд, и всё, что поварам было непонятно. Пришлите мне — поправлю.
- **Когда расхождений нет три дня подряд,** принтер на кухне можно выключать.

## Что проверить на живом Poster в первый день

Эти вещи нельзя было проверить без настоящего аккаунта:

- **Тип заказа.** Стоят ли пометки «С собой», «В зале», «Доставка». Система берёт их из поля чека `service_mode`. Если пометок нет, пришлите пример чека: поправлю за полчаса.
- **Номер заказа.** Совпадают ли последние три цифры номера чека с тем, что видит гость на своём чеке. Если гостю называют другой номер, скажите какой, я переключу.
- **Валюта и часовой пояс.** Взялись ли они из Poster (видно в «Настройках»).

## Обновления

После первого запуска сервер обновляется сам из GitHub, руками ничего делать не нужно.

1. В репозитории на GitHub: Settings → Secrets and variables → Actions.
   - Вкладка **Variables**: `DEPLOY_HOST` — IP сервера; `DEPLOY_URL` — адрес системы, например `https://1-2-3-4.sslip.io`.
   - Вкладка **Secrets**: `DEPLOY_SSH_KEY` — закрытый SSH-ключ, у которого открытая часть лежит на сервере в `~/.ssh/authorized_keys`.
   Пока `DEPLOY_HOST` не задан, новые версии только проверяются тестами и на сервер не уходят.
2. Новая версия выкатывается меткой: `git tag v1.0.0-beta.2 && git push --tags`, или кнопкой «Run workflow» в Actions → deploy.
3. Сначала прогоняются все тесты. Если хоть один не прошёл, сервер не трогается. Данные, пароли и резервные копии на сервере при обновлении сохраняются. Экраны на кухне сами перезагрузятся на новую версию, неотправленные отметки не потеряются.
