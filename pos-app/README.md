# KDS в кассе Poster

Приложение для POS-платформы Poster. Это один JS-файл, который Poster загружает в кассовый терминал. Работает в веб-кассе `{account}.joinposter.com/pos` и в приложении `pos.ps`.

## Что умеет

| Где в кассе | Кнопка | Что показывает |
|---|---|---|
| Окно заказа | **Готовность** | Готовность этого заказа: «Готово 2 из 3», по станциям (Кухня 1/2, Бар 1/1), каждая позиция: ждёт / готовят (кто) / готово (кто), отдан ли заказ. Обновляется каждые 3 секунды. |
| «Функции» | **KDS** | Экран станции, к которой привязана касса, прямо в окне кассы: бармен у кассы отмечает «взял / готово», не отходя от неё. |
| — | — | При закрытии чека сразу сообщает серверу KDS. Заказ попадает на экраны, не дожидаясь вебхука или опроса, что важно при быстром обслуживании. |

## Подключение кассы

1. Админка KDS → «Экраны и кассы» → «+ Касса Poster». Выберите станцию, которую будет показывать кнопка «KDS».
2. В кассе нажмите «Готовность» или «KDS» и введите 6-значный код. Код действует 15 минут и срабатывает один раз.
3. Касса запомнит подключение. Чтобы отключить кассу: кнопка «KDS» → «Отключить эту кассу» или «Отключить» в админке.

Касса обращается к KDS с токеном устройства, как обычный экран. Куки не используются, поэтому запросы из кассы разрешены с любого адреса (CORS).

## Сборка и загрузка в Poster

```bash
# 1. Собрать с адресом вашего KDS (адрес вшивается в файл)
KDS_URL=https://kds.example.com npm run pos:build        # → pos-app/dist/bundle.js

# 2. Загрузить в Poster (dev.joinposter.com → ваше приложение: ID и секрет)
POSTER_APP_ID=… POSTER_APP_SECRET=… KDS_URL=https://kds.example.com npm run pos:upload
```

Загрузка — тот же запрос, что в официальном шаблоне Poster: `application.uploadPOSPlatformBundle`, подпись `md5(application_id:md5(bundle):application_secret)`.

**Разработка:** `KDS_URL=http://localhost:3000 npm run pos:dev` поднимает `https://localhost:5173`. В кассе `pos.ps` вверху слева откройте вкладку prod</>, переключите приложение в режим разработки и введите этот адрес (как в официальном шаблоне Poster). Один раз откройте адрес в браузере и примите самоподписанный сертификат.

## Важно

- **Нужен публичный HTTPS-адрес KDS** (облачный сервер или временный домен `*.sslip.io`). Касса Poster работает с публичного HTTPS-адреса. Современные браузеры спрашивают разрешение или блокируют запросы с такой страницы к адресу в локальной сети, поэтому KDS только в локальной сети заведения (`MODE=local`) для кнопки в кассе не подойдёт.
- **Встроенный экран** показывается в рамке. KDS разрешает показ внутри `*.joinposter.com` и `pos.ps` (переменная `FRAME_ANCESTORS`). Если касса откроется с другого адреса, добавьте его туда.
- **Проверено на имитации кассы**, а не на живом Poster. В браузере эмулировались `Poster.interface`, `Poster.on`, `Poster.orders.getActive` и `Poster.settings`. Что сверить на живой кассе:
  - [ ] совпадает ли `order.id` из `Poster.orders.getActive()` с номером чека на сервере (`transaction_id`). Если нет, заказ всё равно находится по столу и кассе;
  - [ ] передаёт ли `afterOrderClose` заказ в данных события;
  - [ ] открывается ли рамка с экраном в нативном `pos.ps`. Если нет, бармену остаётся обычный экран станции, а кнопка «Готовность» работает в любом случае: ей рамка не нужна.
